# Security

If you find a vulnerability (access to an opponent's hidden information, bypassing server authority, access to the admin console, account data leak), **do not open a public issue**.

Use "Report a vulnerability" in the Security tab of the `foilengine` repository (GitHub private reporting). Describe the vulnerability, how to reproduce it, and its impact.

We respond within 7 days. Please leave time for a fix before any disclosure.
